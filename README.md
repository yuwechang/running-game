# 🥔 Potato Runner

這是「阿右薯叔 GameDev」YouTube 頻道  
**Godot 4.7 零基礎遊戲開發教學系列**所製作的 2D 跑酷遊戲專案。

從建立第一個 Godot 專案開始，一步一步完成角色控制、動畫、障礙物、UI、音效，以及遊戲發布。

## 🎮 遊戲操作

- `↑`：跳躍
- `↓`：滑行

## 🛠 開發環境

- Godot 4.7
- GDScript

## 📥 下載專案

點選 GitHub 頁面右上方的：

**Code → Download ZIP**

下載並解壓縮後，使用 Godot 開啟專案資料夾中的 `project.godot` 即可。
